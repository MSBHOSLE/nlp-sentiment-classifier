An end-to-end **Natural Language Processing (NLP) Sentiment Classification System**. Evaluates customer feedback, reviews, and social signals via **TF-IDF statistical baselines** alongside optimized **DistilBERT transformer serving**.

---

## ⚡ Highlights

- **Multi-Class Sentiment Inference**: Categorizes input into Positive, Negative, and Neutral polarity with calibrated confidence probabilities.
- **Fast Inference Pipeline**: Low-latency tokenization and prediction runtime.
- **Microservice Serving**: Pre-configured RESTful endpoint for batch and streaming inference.
